# DevToolkit

**A powerful suite of browser-based tools to supercharge your development workflow.**  
All tools run 100% in your browser — no server communication, no data storage, and completely secure.

---

## 🔐 Security & Encoding

Tools to hash, encode, decode, and generate secure data:

- **[Text Hasher]** - Hash text using popular algorithms (MD5, SHA variants, etc.)
- **[JWT Encoder/Decoder]** - Encode and decode JSON Web Tokens.
- **[Password Strength]** - Check the strength of passwords.
- **[Password Generator]** - Generate secure, customizable passwords.

## 🔄 Data & Conversion

Convert and manipulate data formats quickly:

- **[JSON ↔ YAML]** - Convert JSON to YAML and vice versa.
- **[JSON ↔ CSV]** - Convert JSON to CSV and back.
- **[Base64 Encoder/Decoder]** - Encode/decode Base64 content.
- **[URL Encoder/Decoder]** - Encode/decode URLs.
- **[Image Converter]** - Convert images between formats.
- **[Text Diff Checker]** - Compare differences between two texts.
- **[Character Counter]** - Count characters, words, and lines.
- **[Lorem Ipsum Generator]** - Generate placeholder text.

## 🌐 Web & Dev Tools

Handy tools for web development and debugging:

- **[Timestamp Converter]** - Convert UNIX timestamps to readable dates.
- **[JSON Formatter]** - Beautify and format JSON data.
- **[Regex Tester]** - Test regular expressions live.
- **[HTTP Request Tester]** - Send and inspect HTTP requests.
- **[Link Previewer]** - View rich previews of URLs.
- **[CSS Minifier]** - Minify CSS code for performance.
- **[CSS / Tailwind Unit Converter]** - Convert px, rem, em, and Tailwind units.

## 🎨 Visual & UI Tools

Design-focused tools for UI/UX and front-end development:

- **[Color Picker]** - Select and copy colors visually.
- **[Color Palette Generator]** - Create custom color palettes.
- **[CSS Gradient Generator]** - Design and export CSS gradients.
- **[Box Shadow Generator]** - Craft complex CSS box shadows.
- **[Grid Layout Generator]** - Generate responsive CSS grid layouts.
- **[Markdown Previewer]** - Preview Markdown content live.
- **[Image to Base64]** - Convert images to Base64 strings.
- **[Image Compressor]** - Compress images for performance.
- **[Sprite Generator]** - Generate image sprite sheets.

---

## ✅ Features

- **Fast & Reliable**: No server latency — everything runs locally in your browser.
- **Private & Secure**: No data is sent or stored externally.
- **Offline Capable**: Many tools work without an internet connection.
